Instances

Every instance of the test and benchmark suites, with its exact Pareto front plotted.

Each card below plots the Pareto front of one instance as computed by zeno: cost on the horizontal axis, makespan on the vertical one, and a staircase through the front’s points. Moving right along the staircase trades a higher cost for a shorter makespan. Hover a point for its values, or Enlarge a card for a larger plot and the table of its points. A card names the instance as its suite does and gives the arguments zeno runs, from which any front can be recomputed:

build/release/zeno -n 10 -t 8 -p 3 -C 3 -D 3

The instances come from the regression tests (the golden instances), the benchmark suites, and a few metric instances whose cities are random points in the plane or on a sphere. How they are built is documented on the sub-pages:

  • Model and data files: what an instance is, and the 2-line and 3-line data files.
  • Generator: the families -C, -D, -E, -W, and the scale options.
  • PDDL: the domain file and the problems zeno pddl writes.
  • Benchmark and golden suites: the suite files and what each one measures.
  • Instances with known fronts: closed forms and fronts checked by an exhaustive oracle.
  • Size guidance: how large an instance zeno solves, and what drives the time.

All instances here but one are symmetric, and their fronts are exact. The non-symmetric metric instance (--hubs apart) is marked bracket: zeno prints the plans it achieves and reports on its standard error which gaps its lower bounds certify; for this instance they do not certify them all.

97 instances in 12 groups, 6,357 front points in all.

Golden instances

Small symmetric instances (\(t \le 5\)) whose fronts were also computed by the brute-force oracle (tests/oracle); zeno’s regression tests compare against them. The -C/-D suffix of a name is historical: the arguments are what zeno runs. 27 instances; source tests/golden/instances.txt.

n = t, two planes

\(n = t\) cities and passengers, \(p = 2\), default generator. 8 instances; source bench/instances/paper-table1.txt.

Quick suite

The short suite run on every pull request. 5 instances; source bench/instances/quick.txt.

Regimes

Many cities and few passengers; balanced; \(p\) close to \(t\); medium; large. Default generator (\(c_i = i\), \(d_i = n + 1 - i\)). 5 instances; source bench/instances/regimes.txt.

Generator families

\(n = 10\), \(t = 8\), \(p = 3\). -C/-D: 1 log, 2 sqrt, 3 identity, 4 power of two, 5 staircase; -r scales before truncation to integers. 7 instances; source bench/instances/families.txt.

Adversarial

Instances where greedy rules fail or search is hard: the LPT counterexample, clustered and near-equal durations, multiples, and a 3-Partition gadget (12 cities forming four triples of sum 100, \(t = 8\), \(p = 4\)). 5 instances; source bench/instances/adversarial.txt.

Scaling: cities

Number of cities \(n\), with \(t = 6\), \(p = 3\). 6 instances; source bench/instances/scaling-n.txt.

Scaling: passengers

Number of passengers \(t\), with \(n = 8\), \(p = 3\). 9 instances; source bench/instances/scaling-t.txt.

Scaling: planes

Number of planes \(p\), with \(n = 8\), \(t = 13\). 12 instances; source bench/instances/scaling-p.txt.

Scaling: duration magnitude

The sqrt family scaled by -r, \(n = 10\), \(t = 8\), \(p = 3\). 5 instances; source bench/instances/scaling-D.txt.

Scaling: distinct durations

Number of distinct durations among \(n = 24\) cities, \(t = 8\), \(p = 3\). 4 instances; source bench/instances/scaling-distinct.txt.

Metric instances

Points drawn at random (seeded) in the plane or on a sphere; every flight lasts the distance between its ends, so central flights satisfy the triangle inequality. With --hubs apart, \(C_I\) and \(C_G\) are two points and the instance is non-symmetric. 4 instances; source site/gen_fronts.py.
